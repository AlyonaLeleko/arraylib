# arraylib

Динамическая библиотека операций над массивами целых чисел.

## Функции

- arr_sum — сумма элементов
- arr_max — максимум
- arr_min — минимум
- arr_average — среднее арифметическое
- arr_count_positive — количество положительных
- arr_count_negative — количество отрицательных
- arr_count_zero — количество нулей
- arr_product — произведение
- arr_median — медиана
